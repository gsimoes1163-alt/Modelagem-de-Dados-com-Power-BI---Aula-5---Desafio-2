# Modelagem-de-Dados-com-Power-BI---Aula-5---Desafio-2

Processo de construção do diagrama:

- Para o atendimento a esse desafio foi utilizada a tabela única de Financial Sample.
- Foram criadas as tabelas dimensão e fato evidenciando um diagrama Star Schema, tais quais:
"F_Vendas" como Tabela Fato, e "D_Produtos_Detanhes", "D_Produtos" e "D_Descontos" como Tabelas Dimensão, com a distribuição respectivamente dos campos advindos da Tabela Única "Financials_origem", conforme instruções na descrição do desafio.

Neste repositório apresento 2 arquivos, um como "Desafio de Projeto - Star Schema Financial Sample.pbix" e o outro como "Desafio de Projeto_Star Schema Diagrama".
